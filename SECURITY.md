# Security Policy

## Reporting vulnerabilities

Do not publish security vulnerabilities in public issues.
Use GitHub Private Vulnerability Reporting when enabled for this repository.
Otherwise contact the repository maintainer privately through GitHub.

Include reproduction steps, affected versions and relevant technical details.
Never include personal databases, passwords, signing keys or private backups.

## Data protection

Productivity App stores personal productivity data locally.
Exported JSON backups may contain private information.
Users should protect their devices and exported backups.

Release signing keys and credentials must never be committed to Git.

## Supported versions

Security fixes will be considered for the latest maintained project version.
